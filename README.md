### 2. AI-Driven Transformer Fault Diagnosis
- Standardized 600+ transformer Frequency Response Analysis (FRA) samples across vendor-specific data formats.
- Automated preprocessing, feature engineering, and data standardization using Python, Pandas, and NumPy.
- Developed interactive FRA curve visualization, multi-sample comparison, and fault prediction across six fault categories.

**Tech:** Python · Pandas · NumPy · Machine Learning · Streamlit

### 3. Traffic Sign Detection and Recognition System

- Improved object detection mAP from approximately 6% to 72% through dataset labeling improvements and class imbalance reduction.
- Integrated YOLOv5 for detection and ResNet18 for fine-grained classification.

**Tech:** Python · PyTorch · YOLOv5 · ResNet18 · OpenCV
